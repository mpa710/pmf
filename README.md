# Primordial Magnetic Field Energy Numerical Solutions

Three .py files to use to plot solutions to the partial differential equation describing Primordial Magnetic Field energy with respect to wavenumber. These are shared to show how the solutions were calculated.

The figures for the paper were created using the .ipynb file. This version iterates through the conditions used in the paper, and should replicate the results. Access the "rawdata" branch to download the .txt files to compare the analytical model to the simulations.
